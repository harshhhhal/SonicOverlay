How it works

Press Start, then SonicOverlay listens to your active Spotify tab.

  1. You press Start

    From the toolbar popup or with Alt+Shift+C, while the Spotify tab is active.

  2. Chrome hands over the tab audio

    The service worker requests a capture stream and passes it to an offscreen document.

  3. A Web Audio analyzer reads it

    An AnalyserNode produces spectrum and waveform data and sends it on at about 50 Hz.

  4. The overlay draws it

    Content script on the page turns the data into bands, smoothing and beats, then paints a canvas.

popup (user gesture) → tabCapture → service worker → offscreen document
offscreen: tab audio → AudioContext → AnalyserNode  (and back to speakers)
          ~50 Hz → content script: bands, smoothing, beat → renderer → canvas

Why each permission

  • tabCaptureCaptures the Spotify tab's audio, only after you press Start.
  • activeTabLets Chrome grant capture for the tab you invoked it on.
  • offscreenHosts the Web Audio analyzer, since service workers have no audio APIs.
  • storageSaves your settings and presets locally.
  • open.spotify.comInjects the overlay and reads the visible track title, artist and cover.
  • i.scdn.coFallback download of the cover image only, for color extraction.

No history, cookies, passwords, accounts, tokens or remote code. No Spotify API and no credentials are used.

Install in two minutes

Download the project, then load it as an unpacked extension.

  1. Download and unzip

    Download SonicOverlay from GitHub and extract it.

  2. Open the extensions page

    Go to chrome://extensions (Edge: edge://extensions) and turn on Developer mode.

  3. Load the folder

    Click Load unpacked and choose the folder with manifest.json.

  4. Start playing on Spotify

    Open open.spotify.com, play something, and reload the tab once if it was already open.

  5. Press Start visualization

    With the Spotify tab active, click the toolbar icon and press Start visualization, or press Alt+Shift+C.

Questions

Why press Start each time?

Chrome requires a click before it can capture tab audio.

The overlay is not showing.

Reload the Spotify tab after installation.

Does it work in the desktop app?

No. SonicOverlay is for Spotify Web Player on desktop Chromium browsers.
